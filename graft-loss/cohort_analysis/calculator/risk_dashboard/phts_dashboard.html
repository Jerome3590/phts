PHTS Risk Calculator – Top Model Workflow

The calculator uses a single model trained on the top 15 causal/importance features only (Combined cohort). Model directory: Combined_top/.

Workflow

  1. Train: train_python_models.py --top_features_only → CatBoost, XGBoost, XGBoost RF on top 15 features; best model by C-index (then AU-PRC) → outputs/models/Combined_top/
  2. SHAP/FFA: run_shap_ffa_workflow.py --model-variant top → causal factors and dashboard_data.json in outputs/shap_ffa/Combined_top/
  3. Deploy: prepare_lambda_dir_phts.py copies Combined_top/ for Lambda; dashboard uses this model only.

Final Model Metrics

Best model and MC-CV metrics are written to outputs/models/Combined_top/best_model.txt. Key metrics:

Metric Description
C-indexConcordance index (primary selection). Mean ± SD and 95% CI across MC-CV splits. Higher = better ranking of risk.
RecallRecall at evaluation time horizon (e.g. 1 year). Fraction of events correctly identified.
AUCArea under the ROC curve at the time horizon.
AU-PRCArea under the precision-recall curve (tiebreaker for best model selection).
